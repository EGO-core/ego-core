# egocore.ai

**egocore.ai** — персональный ИИ-ассистент нового поколения.

Универсальный голосовой и текстовый помощник, работающий в Telegram, MAX и веб-интерфейсе. Отвечает на любые вопросы и интегрируется с любыми платформами, сервисами и бизнес-процессами.

## Возможности

- 🎙️ **Голосовой ввод и вывод** — распознавание речи через OpenAI Whisper, синтез через OpenAI TTS (голос Nova)
- 🤖 **Claude Sonnet** — интеллектуальные ответы на любые вопросы
- 📱 **Мультиплатформенность** — Telegram, MAX Messenger, Web и любые другие каналы
- 🔌 **Открытая интеграция** — подключается к любым платформам, API и бизнес-сервисам
- 🧩 **Модульная архитектура** — новые модули подключаются по контексту разговора
- 🌐 **Веб-интерфейс** — голосовой чат прямо в браузере

## Интеграции

egocore.ai поддерживает интеграцию с любыми внешними платформами и сервисами:

- Маркетплейсы и биржи услуг
- CRM и ERP системы
- Платёжные шлюзы
- Сервисы бронирования и записи
- Базы знаний и документации
- IoT и умный дом
- И любые другие через REST API / Webhook

## Технологии

- **AI**: Anthropic Claude Sonnet, OpenAI Whisper STT, OpenAI TTS
- **Backend**: Python (Telegram/MAX боты), Node.js + Express (веб-панель)
- **Frontend**: React + Vite + TypeScript + Tailwind CSS
- **Infrastructure**: Docker, PostgreSQL, SQLite

## Структура

```
ego-core/

```
